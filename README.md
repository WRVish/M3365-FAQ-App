# 📋 M365 FAQ Code App

> A modern, responsive **Microsoft 365 FAQ application** built as a **Power Apps Code App**, powered by a SharePoint list and built with React + TypeScript.

---

## 📂 Project

The full source code, setup guide, and documentation live inside the project folder:

👉 **[m365-faq-code-app/README.md](./m365-faq-code-app/README.md)**

---

## ✨ Highlights

- 🗂 Category sidebar with live search & highlight
- 📝 Markdown-rendered answers with attachment support
- 📄 Pagination, pinned items & copy-to-clipboard
- 📱 Fully mobile responsive
- ⚡ Built with React 19, Vite, and Power Platform CLI
