# 📋 M365 FAQ Code App

> A modern, responsive **Microsoft 365 FAQ application** built as a Power Apps Code App, connected to a SharePoint list as its data source.

## ✨ Features

| Feature                  | Description                                                    |
| ------------------------ | -------------------------------------------------------------- |
| 🗂 **Category Sidebar**   | Navigate FAQ categories from a persistent left sidebar         |
| 🪗 **Accordion / Modal**  | Toggle between inline accordion and full-screen modal view     |
| 📝 **Markdown Answers**   | Answers render with full Markdown support (bold, lists, links) |
| 📎 **Attachments**        | SharePoint attachments shown as clickable links below answers  |
| 🔍 **Search & Highlight** | Live search with term highlighting in results                  |
| 📄 **Pagination**         | Configurable per-page limit with page number navigation        |
| 📱 **Mobile Responsive**  | Slide-out sidebar on mobile, icon-only toggle controls         |
| ⭐ **Pinned Items**       | Pinned FAQs float to the top with a ★ indicator                |
| 📋 **Copy to Clipboard**  | One-click copy of Q&A + attachments for sharing                |

## 🏗 Tech Stack

- **React 19** + **TypeScript** — UI framework
- **Vite 8** — Build tool
- **react-markdown** + **remark-gfm** — Markdown rendering
- **lucide-react** — Icon library
- **Power Platform CLI (`pac`)** — App publishing
- **SharePoint Online** — Data source via Power Apps connector

## ✅ Prerequisites

Before you start, make sure you have:

- [ ] **Node.js v22+** — [Download](https://nodejs.org/)
- [ ] **Power Platform CLI (`pac`) v2.7.4+** — [Install Guide](https://learn.microsoft.com/en-us/power-platform/developer/cli/introduction)
- [ ] A **Microsoft 365** account with Power Apps access
- [ ] A **SharePoint site** with the FAQ list created (see Step 1 below)
- [ ] At least **Contribute** permission on the SharePoint list

## 🚀 Developer Setup Guide

### Step 1 — Create the SharePoint List

1. Go to your SharePoint site → **Site Contents** → **New** → **List**
2. Name it `M365 FAQs`
3. Add these columns:

| Column        | Type                   | Required | Notes                             |
| ------------- | ---------------------- | -------- | --------------------------------- |
| `Title`       | Single line of text    | ✅        | The FAQ question                  |
| `Answer`      | Multiple lines of text | ✅        | Supports Markdown                 |
| `Category`    | Choice                 | ✅        | e.g. Teams, Outlook, SharePoint   |
| `SubCategory` | Choice                 | ❌        | e.g. Setup, Security, Usage       |
| `Active`      | Yes/No                 | ✅        | Default: Yes. Hides inactive FAQs |
| `Pinned`      | Yes/No                 | ❌        | Pinned items appear first         |

4. Add a few sample items with `Active = Yes` to test with.

> 💡 You can also import from a CSV file via **Site Contents → New → List → From Excel**.

---

### Step 2 — Create a Power Apps Connection

1. Go to [make.powerapps.com](https://make.powerapps.com)
2. Select your environment
3. Click **Data → Connections → New connection**
4. Search for **SharePoint** → Connect directly → Sign in
5. Select your SharePoint site → **Create**

---

### Step 3 — Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/m365-faq-code-app.git
cd m365-faq-code-app/m365-faq-code-app
```

---

### Step 4 — Install Dependencies

```bash
npm install
```

---

### Step 5 — Configure the App

#### 5a. Update `power.config.json`

```json
{
  "environmentId": "YOUR_ENVIRONMENT_ID",
  "connectionReferences": {
    "YOUR_CONNECTION_REFERENCE_GUID": {
      "dataSets": {
        "https://YOUR_SHAREPOINT_SITE_URL": {
          "dataSources": {
            "m365_faqs": {
              "tableName": "YOUR_SHAREPOINT_LIST_ID"
            }
          }
        }
      }
    }
  }
}
```

- **`environmentId`** — Run `pac org list` to find yours
- **`tableName`** — Go to SharePoint List → **Settings → List Information** → copy the List ID (GUID)

#### 5b. Update `src/fieldMap.ts` (if needed)

If your SharePoint columns have different internal names, add them:

```typescript
export const fieldMap = {
  subCategory: ["SubCategory", "Sub_x0020_Category", "field_3", /* add yours */],
};
```

#### 5c. Configure App Behaviour (`src/config.ts`)

```typescript
export const appConfig = {
  maxItemsPerPage: 5,       // FAQs shown per page
  uiMode: "accordion",     // "accordion" | "modal"
};
```

---

### Step 6 — Authenticate with Power Platform CLI

```bash
pac auth create
pac auth list
pac org list
```

Switch environment if needed:

```bash
pac auth select --index 1
```

---

### Step 7 — Build the App

```bash
npm run build
```

---

### Step 8 — Publish to Power Apps

```bash
pac code push --solutionName "M365 FAQ Code App"
```

The CLI will output a URL — open it to view your live app! 🎉

## ⚙️ Configuration Reference

| Property          | File                | Default       | Description                           |
| ----------------- | ------------------- | ------------- | ------------------------------------- |
| `maxItemsPerPage` | `src/config.ts`     | `5`           | Number of FAQs per page               |
| `uiMode`          | `src/config.ts`     | `"accordion"` | `"accordion"` or `"modal"`            |
| Field names       | `src/fieldMap.ts`   | —             | Maps SharePoint columns to app fields |
| Environment       | `power.config.json` | —             | Target Power Apps environment         |
| SharePoint URL    | `power.config.json` | —             | Target SharePoint site                |
| List ID           | `power.config.json` | —             | SharePoint list GUID                  |

## 🐛 Common Issues

| Problem               | Fix                                                                   |
| --------------------- | --------------------------------------------------------------------- |
| `pac pcf push` error  | Use `pac code push`, not `pac pcf push`                               |
| Wrong environment     | Run `pac auth list` → `pac auth select --index N`                     |
| Data not loading      | Check `tableName` (List ID) and SharePoint URL in `power.config.json` |
| SubCategory not found | Add your column's internal name to `src/fieldMap.ts`                  |
| Node.js error         | Upgrade to Node.js v22 LTS                                            |
